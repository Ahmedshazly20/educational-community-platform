# AUDIT — تدقيق وبناء لوحة إدارة مجتمع ثانوية عامة

## 1. الحالة المبدئية للمشروع
بدأ العمل على مستودع React + Vite + Tailwind CSS v4 فارغ (Greenfield) بدون أي شاشات مسبقة أو قاعدة بيانات محلية مهيأة.

## 2. تغطية المتطلبات
| الوحدة / الميزة | الحالة | التفاصيل |
| --- | --- | --- |
| المصادقة و MFA و Idle Logout | مكتمل | تسجيل الدخول، تحقق TOTP إلزامي لـ `admin` و `payments_reviewer`، تحذير خمول عند 28 دقيقة وخروج عند 30 دقيقة. |
| حراسة الصلاحيات RBAC | مكتمل | مصفوفة §3 كاملة في `src/lib/permissions.ts` مع إخفاء عناصر القائمة الجانبية وحماية المسارات وتوجيه `/unauthorized`. |
| لوحة التحكم | مكتمل | تنبيه أحمر عند نقص `terms.access_ends_at`، بطاقات المؤشرات قابلة للنقر، جدول الاشتراكات حسب الترم، أحدث 10 أحداث تدقيق. |
| الهيكل الأكاديمي | مكتمل | إدارة `stages`، `tracks` (مع تنبيه `is_active`)، `courses`، `track_courses` (مع تحذير المواد المشتركة وفك الارتباط)، `terms`، مصفوفة تغطية المنهج. |
| المحتوى التعليمي | مكتمل | متصفح شجرة المنهج بدون وحدات (Units)، محرر الدرس (TipTap + رابط موثّق بالنطاقات + أسئلة سريعة)، قائمة تحقق النشر، معاينة الطالب، حماية البيانات المرتبطة. |
| الأسعار والاشتراكات | مكتمل | مصفوفة المسار × الترم، منع تداخل أو تسعير مادة منفردة، سجل الاشتراكات ومنح اشتراك يدوي مع التوجيه للمدفوعات عند الرغبة. |
| المدفوعات | مكتمل | تبويبات معلّق / مقبول / مرفوض، درج المراجعة، عرض صورة الإيصال عبر رابط موقّع، قبول مع معالجة الأخطاء ورفض بسبب إلزامي. |
| الطلاب | مكتمل | بحث وترشيح وفرز، صفحة الطالب الشاملة، تمديد التجربة، حظر/إلغاء حظر، تغيير المسار/الموقع، إعادة تعيين جلسة الجهاز. |
| الامتحانات والتصحيح والنتائج | مكتمل | معالج 4 خطوات، استيراد أسئلة Excel (بحد أقصى 500)، جدولة الجلسات وجمهورها، كشف التعارض، المراقبة كل 15 ثانية، تصدير/استيراد التصحيح المجهول، اعتماد النتائج، مراجعة المقالي للمدير العام. |
| الإعلانات والتقارير والفريق والتدقيق والإعدادات ونهاية العام | مكتمل | كل الشاشات مربوطة عبر واجهة `AdminApi` الموحدة مع دعم التصدير Excel والالتزام الصارم بعدم إضافة أي جداول/أعمدة غير موجودة. |
