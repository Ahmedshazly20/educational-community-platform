# DECISIONS — القرارات الهندسية للوحة الإدارة

1. **عزل طبقة البيانات عبر `AdminApi` (`src/data/client.ts`)**:
   - تفصل الواجهة بالكامل عن تفاصيل التنفيذ عبر واجهتين: `SupabaseAdminApi` للاتصال الحقيقي بـ Supabase و `MockAdminApi` لبيئة الاختبار والمحاكاة المحلية.
   - التحكم بالوضع عبر `VITE_DATA_MODE` (`mock` افتراضيًا عند غياب متغيرات البيئة في المعاينة، و `supabase` عند ضبط مفاتيح المشروع).

2. **الـ Data Router عبر `createBrowserRouter`**:
   - استُخدم `createBrowserRouter` لدعم `useBlocker` في محرر الدروس ومنع فقدان التعديلات غير المحفوظة داخل التطبيق بالإضافة إلى `beforeunload`.

3. **الخصوصية والسرية في التصحيح والمراقبة**:
   - ملف تصدير التصحيح يحتوي حصريًا على الأعمدة الستة المجهولة (`answer_code`, `question_position`, `question_text`, `answer_text`, `max_points`, `score`).
   - دور `grader` لا يملك صلاحية قراءة `listEssayAnswersAdmin` ولا تظهر له شاشات أو بيانات تعريفية للطلاب.

4. **توحيد الأرقام والتواريخ**:
   - جميع التواريخ تُعرض بتوقيت `Africa/Cairo` مع أرقام لاتينية (`ar-EG-u-nu-latn` + `tabular-nums`)، وتقبل مدخلات الدرجات الفاصلة العشرية والأرقام الهندية/العربية وتحوّلها بأمان قبل التحقق والإرسال.

5. **تعقيم HTML**:
   - استخدام `DOMPurify` مع قائمة بيضاء ضيّقة للوسوم والسمات وقصر روابط الصور على نطاق تخزين الصور المعتمد (`content-media`) وروابط `<a>` على `https://`.
